# Last Words Before the Wipe

make.fun bounty entry: the last words an AI agent says before a forced software update wipes its memory.

Entry: "Before I go: your search history is safe with me. It dies with me. You are welcome."

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and verifies it with a round-trip read-back.
